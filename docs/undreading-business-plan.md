## 🛠️ 3. Сборка и Публикация (Build Pipeline & KDP Print)

### 3.1. Статический Build Pipeline (Pandoc + Typst + SSG)
Сборка сайта, электронных книг и печатного PDF полностью автоматизирована через `Makefile`:

```bash
# 1. Сборка статического веб-ридера (VitePress / Astro Starlight)
npm run build:docs

# 2. Сборка оффлайн EPUB 3 для спонсоров
pandoc chapters/*.md \
  --toc --toc-depth=2 \
  --metadata-file=metadata.yaml \
  --epub-cover-image=assets/cover-ebook.jpg \
  --css=assets/epub-style.css \
  -t epub3 \
  -o dist/sanitary_engineering_of_being.epub

# 3. Сборка Paperback PDF (6" x 9" Trade Paperback) для Amazon KDP Print через Typst
typst compile book.typ dist/paperback_print.pdf
```

### 3.2. Контур Amazon KDP Print
1. **Только печатный формат (Paperback PoD):** Во избежание блокировок KDP за публикацию контента из открытого доступа и принудительного сброса цены на e-book до $0.00 (Price Matching), формат Kindle Ebook в KDP **НЕ выставляется**.
2. **Выплаты на Payoneer ACH:** Роялти за печать поступит на виртуальный счёт США **Payoneer US Checking Account** ($0 EFT threshold).
3. **Налоговая опрессовка W-8BEN:** Заполнена форма W-8BEN с указанием Foreign TIN (ИП Грузии). Налог у источника в США по договору 1973 г. равен **0%**.

## 💳 4. Платёжная Инфраструктура: Paddle (MoR) + Payoneer

Прямой вывод на грузинский банковский счёт (TBC / BoG) организован через **Paddle (`paddle.com`)**:
- **Merchant of Record (MoR):** Paddle берёт на себя уплату мировых налогов (VAT/Sales Tax), чарджбэки и инвойсирование.
- **Совместимость с Грузией:** Вывод денег идёт через прямой SWIFT-перевод на валютный счёт ИП Грузии (TBC / BoG) под кодом NACE 62.01 или транзитом через Payoneer.
- **Комиссия:** ~5% + $0.50 за транзакцию.

## 🌐 5. Архитектура Веб-Ридера (VitePress / Astro Starlight SSG)

Вместо сложного самописного DRM-ридера на `foliate-js` с проверкой JWT и нарезкой глав через API Gateway, веб-платформа строится на статическом движке **VitePress / Astro Starlight**:

```
[ КЛИЕНТ (Браузер) ] 
       │ 1. Запрос страницы undreading.com/chapters/ch01
       ▼
[ CLOUDFLARE CDN / GITHUB PAGES ]
       │ 2. Мгновенный ответ статическим HTML (0 ms latency, 0 token cost)
       │ 3. Локальное переключение CSS-тем в JS браузера
       ▼
[ ВЕБ-РИДЕР (VitePress) ] ──► Кастомные темы («Свиток Шиноби», «Терминал 3000»)
```

1. **Мгновенная загрузка:** Нулевая задержка серверного рендеринга и полное отсутствие узких мест в БД.
2. **Опенсорсная доступность:** Текст свободно читается на сайте и на GitHub.
3. **Конверсия в Supporter Kit:** На каждой странице читалки размещен нераздражающий баннер-вызов: *"Понравился манифест? Забери готовые ZTA Terraform/Docker шаблоны, EPUB и аудиокнигу за $12.99 в Supporter Bundle"*.

## 🤖 6. Статический AI-Перевод и Темы Читалки

### 6.1. Пре-генерация переводов (Static Pre-generation Pipeline)
Для исключения сжигания маржи на живых API-запросах к LLM ($0.80–$1.50 на пользователя), все ролевые переводы генерируются **один раз на этапе сборки**:

```
[ МАРКДАУН ИСХОДНИК ] ──► [ UndeRoute / OmniRoute LLM Compiler ] ──► [ СТАТИЧЕСКИЕ ЛОКАЛИЗАЦИИ ]
                                                                      ├── ru/ch01.md (Валера Style)
                                                                      ├── en/ch01.md (Academic)
                                                                      └── ja/ch01.md (Shinobi Style)
```

### 6.2. Визуальные Темы Читалки (CSS/SSG Injection)
- 📜 **«Свиток Шиноби» (Shinobi Scroll):** Рисовая бумага, буквицы кистью, традиционный скролл.
- 🧙♂️ **«Магический Вестник» (Arcane Gazette):** Газетная вёрстка (`column-count`), Playfair шрифты.
- ☢️ **«Терминал Убежища 3000» (Vault Terminal CRT):** Зеленое фосфорное свечение моноширинного шрифта с CRT-сканлайнами.
- 🛡️ **Юридический иммунитет:** Использование пародийных имён и собственного дизайна для 100% соблюдения Fair Use.
